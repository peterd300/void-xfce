# Installation of XFCE4 desktop in Void Linux


Custom install script for Void-Linux, with custom XFCE desktop.

I make several seperated install scripts, so can enable or disable the scripts in the install.sh script


## Installation of XFCE4 desktop with several programs

- Geany 		- text editor
- Thunar 		- file manager with plugins
- Kitty 		- terminal
- Ghostty		- terminal
- Fish			- shell
- Firefox		- Internet Browser
- Flameshot		- Screen grabber

## Some terminal utils
- fzf
- starship and zoxide

##  Fonts, download during install not via repo
Enable or disable these in the install.sh script

- Iosevka
- Iosevka Terminal
- JetbrainsMono (nerd)
- Fira Mono
- Firacode
- Hacknerd
